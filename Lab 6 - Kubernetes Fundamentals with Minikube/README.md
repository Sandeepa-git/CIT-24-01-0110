
# Lab 6 - Kubernetes Fundamentals with Minikube

This repository contains the manifests, checkpoint answers, and diagnostic screenshots for the Week 7 Kubernetes Fundamentals Practical Lab.

## Directory Structure

* `k8s/`: Subdirectory containing all 9 Kubernetes manifests for the application tiers.
* `screenshots/`: Diagnostic screenshots for tasks 1.1 to 10.1.
* `answers.md`: Written responses to all checkpoint questions.

## Setup & Deployment Instructions

1. Start Docker Desktop.
2. Open terminal and run:
   ```bash
   minikube start --driver=docker
   ```
